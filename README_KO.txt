그란 킹덤 로컬 전쟁 패치 1.13 — 최신 통합 재배포본
2026-10-07 / 클라이언트47 · 전쟁 서버29 · 작전 종료37

지원 환경과 준비물
- Windows PC + Vita3K / 일본판 PCSG00474 / 게임 업데이트 1.06.
- 본인이 보유한 게임이 Vita3K에서 정상 실행되어야 합니다.
- 처음 설치할 때 해당 1.06 게임의 복호화 SELF eboot.bin이 필요합니다.
  보통 decrypted_selfs\PCSG00474\eboot.bin에 있습니다.
- 게임 본편·업데이트·DLC 데이터·펌웨어·라이선스는 포함하지 않습니다.
  설치 도구가 본인의 복호화 실행파일에서 필요한 통신 테이블을 추출합니다.
- 한글화 데이터 파일은 교체하지 않습니다. DLC 직업/스토리 접근 수정에는 해당 콘텐츠 데이터가 필요합니다.

필수 그래픽 설정
OpenGL 사용 / VSync 끄기(OFF).
OpenGL을 끄라는 뜻이 아닙니다. 게임별 설정을 쓰면 그란 킹덤에도 적용하세요.
패치 도구는 그래픽 설정을 자동 변경하지 않습니다.

접속 방식
자기 PC의 서버를 켜고 게임의 온라인 메뉴로 AI 국가전에 참가합니다.
서버 주소는 127.0.0.1:80입니다. READY 서버 창을 플레이 중 열어 두세요.
각 사용자의 AI 전쟁·계정·순위·파견·캠페인 데이터는 각 PC에서 별도로 생성됩니다.
이 패키지는 공용 인터넷 멀티플레이 또는 PS Vita 실기용 서버 패키지가 아닙니다.

처음 설치하는 사람
1. ZIP 전체를 전용 폴더에 압축 해제합니다. 압축 안에서 CMD를 직접 실행하지 마세요.
2. Vita3K와 모든 GK 서버 창을 종료합니다.
3. 1_Install_Standard.cmd 실행.
   성장8배로 시작하려면 대신 Optional_Growth_8x.cmd를 실행합니다.
4. 설치된 파일 선택 창이 뜨면 아래 실행파일을 선택합니다.
   ux0\patch\PCSG00474\eboot.bin, 없으면 ux0\app\PCSG00474\eboot.bin.
5. 복호화 파일 선택 창이 뜨면 decrypted_selfs\PCSG00474\eboot.bin을 선택합니다.
   두 파일의 이름은 같지만 역할이 다릅니다. 일반 ELF 덤프도 복호화 SELF를 대체하지 못합니다.
6. INSTALLED 확인 → 2_Start_Local_War.cmd 실행.
7. SELFTEST OK / Finish 37 / READY 확인 후 Vita3K에서 게임을 실행합니다.
   다음부터는 2_Start_Local_War.cmd로 서버를 켜고 게임을 시작하면 됩니다.

기존 사용자가 갱신하는 방법
1. Vita3K와 모든 GK 서버 창을 종료합니다.
2. 이 ZIP 전체를 기존 패치 폴더에 덮어 압축 해제합니다.
   CMD/PS1/EXE가 기존 public-install.json 또는 active-install.json과 같은 폴더에 있어야 합니다.
   기존 설치 기록, protocol.dat, war-state.json, local-users.json, 세이브, backups는 유지하세요.
   새 하위 폴더에서 시작하면 기존 계정·전쟁 진행을 이어받지 못할 수 있습니다.
3. 1_Update_Existing_Install.cmd 실행 → INSTALLED/ALREADY INSTALLED 확인.
   지원되는 기존 클라이언트30/31/32/34/38/41/42/43/45/46/47을 확인하며 표준/성장8배 설정을 유지합니다.
   정상 protocol.dat가 있으면 복호화 파일을 다시 요구하지 않습니다.
4. 2_Start_Local_War.cmd 실행 → Finish 37 / READY 확인 후 게임 실행.
   이전 1.5 사용자는 서버도 갱신해야 합니다. 새 서버 첫 시작 때 연구가 한 번 초기화됩니다.

  피해를 임의로 추정하여 표시하지 않습니다. 모든84개 전장 공통 적용입니다.

  반영을 확인했으며, 배정하는 깃발59종·말19종 모두 저장 처리에 통과했습니다.
  실제 Vita3K 실행 검사가 아닌, 게임 코드와 일부 모의 메모리를 이용한 검사입니다.
  획득 확률은 깃발7%, 말1%를 유지합니다. 이미 소유한 종류는 다시 나오지 않습니다.
  '승리했지만 전리품 없음' 자체가 항상 오류인 것은 아닙니다.
- 게임 코드의 부대 해석80개, 실전 부대 스킬 슬롯1028개, HUD 정기 갱신1008개,
  깃발/말78종의 소지품 저장 경로를 검사했습니다. 설치 레시피와 기존 계약/랭크/
  건물HP 회귀 검사도 수행했습니다. 실제 Windows+Vita3K 전투 행동·화면·사용자
  세이브 파일의 저장은 설치 후 확인해야 합니다.
- 일반 전장 보상량, 성장8배 선택, 경험치3배, 공훈3배 및 기존 진행을 유지합니다.

비밀보상 확인·수령 안내
1. 국가 계약 상태로 해당 국가가 참여하는 같은 전장 지역에서 적을10회 격퇴합니다.
   서로 다른 전장 지역의 격퇴 수를 단순히 합산하는 조건은 아닙니다.
2. 격퇴10회 외에 계약국과 캠페인 결과 조건을 충족해야 합니다.
   해당 국가가 이긴 전장 또는 원본이 요구하는 전과 조건을 충족한 전장에서
   3개 비밀보상 항목을 판정합니다. 조건을 충족하지 못하면 두루마리가 잠겨 있습니다.
3. 캠페인이 끝난 뒤 온라인에 다시 접속하여 전쟁 결과·보상 처리를 끝내세요.
   전장 입장 전 두루마리를 누른다는 것만으로 장비가 지급되는 구조는 아닙니다.
   게임의 결과 보상 처리에서 해금 판정에 통과한 장비를 소지품에 추가합니다.
4. 이 버전에서는 비밀보상 기준과 일반 보상량을 추가로 변경하지 않았습니다.
   결과 보상 후에도 장비가 없으면 4_Collect_Logs.cmd의 진단 ZIP과 해당 결과
   화면을 함께 보내면 실제 수신한 결과를 기준으로 추가 확인할 수 있습니다.

  원본 해금 판정에 포함되므로 아무 전장에서10회 이기면 자동 해금되는 것은 아닙니다.

  실제 Windows+Vita3K 렌더링·전투·승리 후 세이브에 저장되는 획득은 추가 확인이 필요합니다.

1.11에서 유지하는 변경 사항

  각 승리마다 최대HP20% 감소, 3승 후 퇴각해도 HP40%, 총5승에 HP0으로 파괴합니다.
  모든84개 전장, 요새/본진/병기 공통 적용입니다. 재전송은 중복 반영하지 않습니다.
  캠페인이 바뀌어도 기존 전장 결과의 피해와 중복 방지를 유지합니다.
- RegisterScore의 이전 랭크를 투표 선택으로 잘못 읽던 오류를 수정했습니다.
  현재 작전의 공성치/격파치/지원치로 각 랭크를 따로 계산해 게임에 전달합니다.
  로컬 서버 승급 기준: F=0, E=25, D=75, C=150, B=300, A=600, S=1200점부터.
  이 기준은 이 로컬 서버의 설정이며 원본 공식 서버의 기준이라는 뜻은 아닙니다.
- 캠페인 누적 전과가 다른 작전에서 다시 가산되는 오류도 수정했습니다.
- 결과 집계에는 전과 점수 대신 실제 참가 용병단 수를 랭크별로 전달합니다.
  원본 게임의 '랭크별 인원 비율' 화면은 막대 비율을 표시합니다.
  랭크별 정확한 숫자는 3_Open_War_Status.cmd의 작전별 인원 표에서 확인하세요.
  게임 결과 화면에 숫자 텍스트를 새로 그리는 UI 변경은 포함하지 않습니다.
- 종료한 작전의 인원 분포를 저장해 재시작/다음 캠페인에도 유지합니다.
- 선택한 계약 전투 횟수를 서버 응답에 반영하고, 클라이언트는 전황 라운드가
  아니라 캠페인 단위로 남은 계약 횟수를 계산합니다. 5전 계약은 5개 캠페인입니다.
  이전 버전에서 이미 만료값이 잘못 저장된 계약은 갱신 후 한 번 다시 계약하세요.
- 기존 연구·세이브·영토·성장8배·경험치3배·공훈3배·병기 투표 마감 수정 유지.
- 서버 회귀 검사 및 SELF 로딩 후 원본 ARM 함수로 계약/랭크/집계/HP 처리 검증.
  실제 Windows+Vita3K 화면 및 보상 동작은 이번 버전에서 추가 확인이 필요합니다.

- 네 국가의 AI 전쟁, 영향력에 따른 영토 변화, 30분 캠페인.
- 전체84개 전장 지도, 다음 캠페인의 작전 진입, 최신 전황 갱신.
- 국가 침공/다음 전장, 전략 병기, 국가 병영 관련 AI 투표와 집계.
- 용병단별 정보·코멘트·상세 조회·부대 파견·플레이어와 AI 순위.
- 국가·지역·거점 이름으로 표시하는 전황·투표 페이지.
- DLC 직업 및 국가 스토리 접근 수정.
- 우리 용병 경험치3배, 선택 가능한 레벨 성장8배.
- 파견 시간에 따른 전투 누적, 전략지령 발동 제한.
- 작전 종료·캠페인 교체 시 강제퇴각 수정, 새 작전 공훈치3배.
기존 국가 계약/계약금은 게임의 원래 계산을 사용합니다.

작전 종료와 공훈치
캠페인30분 / AI 전황 라운드5분 / AI 시뮬레이션15초 간격.
작전 전투 마감은 캠페인 시작29분30초 시점입니다.
늦게 참가하면 남은 시간만 진행합니다. AI의5분 라운드가 작전 종료는 아닙니다.
마감 시 승패를 확정하고 게임의 정상 작전 종료 처리가 인식하는 정보를 보냅니다.
종료 정보를 아직 받지 못한 참가 작전은 캠페인 교체 때 삭제하지 않습니다.
지연 요청·재접속·서버 재시작에도 같은 종료 결과를 다시 제공합니다.
전황 페이지에서 작전별 남은 시간과 종료 후 승리국을 확인할 수 있습니다.
이전 버전에서 이미 강제퇴각해 잃은 보상은 소급 지급하지 않습니다.

새로 얻는 우리 작전 공훈치3개 항목은3배입니다. 기본10 → 실제30.
전장 안 점수와 서버 집계는 같은 값을 쓰며 서버에서 다시3배를 곱하지 않습니다.
기존 누적 점수와 병기/지령 등의 차감 비용, 원본 공훈치 상한은 유지합니다.

성장 옵션
두 모드 모두 우리 용병의 새 경험치 획득량3배와 작전 공훈치3배를 적용합니다.
현재 용병과 앞으로 고용할 용병에 적용하며 기존 누적 경험치를 소급 증가시키지 않습니다.
경험치 배율은 적/NPC에 적용하지 않습니다. 일부 보상 설명의 기본 EXP 표기는 원본일 수 있습니다.

표준판: 원본 레벨 성장 / 원본 배분 포인트.
성장8배판: 우리 용병의 HP·물리 공격력·물리 방어력·마법 공격력 레벨 성장분8배.
계산: 레벨1 기본값 + 8 × (현재 레벨 기본값 - 레벨1 기본값).
레벨1은 원래대로 시작합니다. 모든 최종 능력치나 피해를8배로 만드는 옵션은 아닙니다.
적과 NPC의 성장은 유지합니다. 배분 포인트를 과도하게 추가하는 구버전 방식은 사용하지 않습니다.
이미 저장된 스탯을 내리거나 세이브를 초기화하지 않습니다.
성장8배 적용/전환: 게임과 서버 종료 → Optional_Growth_8x.cmd.
표준판으로 전환: 게임과 서버 종료 → 1_Install_Standard.cmd.

파견과 전략지령
파견은1분마다1전투씩, 한 번에 최대255전투까지 누적합니다.
예:10분10전투 / 1시간60전투 / 4시간15분255전투.
서버를 껐다 켜도 시작 시각으로 계산합니다. 승리는 기존 AI 계산으로 집계됩니다.
255전투를 넘으면 귀환 후 재파견하세요. 이미 귀환한 보상은 다시 지급하지 않습니다.
6종 전략지령을 합쳐 각 진영1회, 한 작전 양측 합계 최대2회입니다.
수동과 AI가 같은 한도를 사용하고 다음 캠페인의 새 작전에는 새 한도가 부여됩니다.

확인·진단·복원
3_Check_Install.cmd: 설치된 클라이언트/서버와 실행 중인 서버 확인.
3_Open_War_Status.cmd: 전황·투표·작전 남은 시간 페이지 열기.

세이브를 과거 백업으로 자동 덮어쓰지 않습니다.

자주 발생하는 상황
Close Vita3K: Vita3K를 완전히 종료한 후 설치하세요.
Wrong decrypted executable: 설치된 일반 파일이 아닌 복호화 SELF 파일을 선택하세요.
Unsupported executable: PCSG00474/1.06 및 지원 실행파일인지 확인하세요.
READY가 안 뜸: 다른 GK 서버 창과80번 포트를 쓰는 프로그램을 확인하세요.
온라인 접속 대기: 게임을 종료하고 최신 서버가 READY인 상태에서 다시 게임을 시작하세요.
최신 전황 수신 실패: 초기 LOGIN ONLY 서버 대신 이 패키지의2_Start_Local_War.cmd로 실행하세요.
검은 배경/프레임 문제: OpenGL / VSync OFF 및 게임별 설정을 확인하세요.
전황 페이지가 이전 화면임: Ctrl+F5로 새로고침하세요.
